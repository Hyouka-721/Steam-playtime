# 回归测试套件（tests/）

本目录把两个页面的**回归测试**与**上线复验**脚本随代码一起版本化，不再散落在临时目录里。
两个页面各走各的轮号：观影页脚本带 `_watch` 后缀，游戏时长页（`index.html`）带 `_index` 或无后缀。

## 目录

```
tests/
├── verify/          # 本地回归套件（对 http://127.0.0.1:8895 跑）
├── online/          # 上线后对 https://hyouka-721.github.io/Steam-playtime/ 复验
└── tools/
    ├── perf-audit.mjs / perf-lazy.mjs / ab-css.mjs   # 常驻性能工具（见 tools/README.md）
    └── archive/     # 历史一次性脚本：取证截图 / 版本号 bump / 数据合并（留档备查）
```

**新增脚本放哪里**：能对着任意版本反复跑的 → `tools/`；只为某一次操作服务的 → `tools/archive/`。

## 踩过的坑（脚本层面）

- ⚠️ **两条线并发时，图标文件名会被对方的批量改名顺手清掉**（第 87 轮实测）：index 侧第 92 轮把图标改成 `<名>-<源图哈希>.png` 并清掉旧名 → 我这边刚生成的 `favicon-watch-16/32/48.png`（不带哈希）被同一个 `favicon-*.png` 的清理一并删掉，套件从 21/21 变成「三个文件 MISSING」并且 `sharp` 直接抛 `Input file is missing`。**规矩**：图标一律叫 `<用途>-<源图哈希>.png`，套件里的期望文件名**从源素材文件名推导**（不要手抄字面量），生成完立刻跑一次套件。
- ⚠️ **「行数相同」是代理判据，对方一改文案就失效**（第 87 轮发现 `verify56` B[700] 红，**第 88 轮已改判**）：它拿 watch 页标题行数去比 index 页标题行数（原话「≤首页」），index 侧第 92 轮把站名从 `My Game Time` 改短成 `Game Time` 后，700px 下 index 只剩 1 行、watch 的 `My Watch List` 仍是 2 行 → 判据红了但页面没有任何问题。**改法不是调阈值**，而是换成观影页自己容器的真实约束：整页不横向溢出 + 标题自身 `scrollWidth ≤ clientWidth` + 标题矩形不压头像矩形（「字号与首页同值」已有 `verify58 A3` 直接守着）。这类「两页文案相同」的代理判据，换代时一律换成各自容器的真实约束，别顺手把阈值调松。
- ⚠️ **调色板 PNG 满幅不透明时 sharp 解出的是 3 通道**（第 88 轮踩到）：`fullBleed()` 用 `.png({ palette: true, colours: 32 })` 压体积后，`raw().toBuffer({ resolveWithObject: true })` 回来的 `info.channels === 3`，照旧读 `data[i + 3]` 会把**隔壁像素的蓝值**当成 alpha → 掩码乱掉、bbox 缩水（实测主体占比从 0.78 掉到 0.64）。**规矩**：`const a = ch === 4 ? data[i + 3] : 255;`。
- ⚠️ **数「主体像素」的判据不能绑素材配色**（第 88 轮）：原先写「亮度 < 120 才算主体」，字面上的原因是前两版素材主体是深色；换成亮蓝 `#2F88FF`（亮度正好 125）就被整片漏掉，只剩黑环 → 占比量出 1.000。改成「非透明**且非近白**」（`rgb` 三通道都 > 243 的算背景，涵盖白底与白色圆孔），阈值按新素材重定 0.938 / 0.779。

- ⚠️ **`scripts/media/watch-variants.mjs` 的回写曾经会给同一张海报插两遍变体字段**（远端出现过 198 个重复键）。根因：写回用「遇到 `poster` 行后往下跳过变体行」这种**位置式**判断，而 `watch.json` 里字段顺序是 `poster` → `poster_w` → `poster_h` → `poster_320` → `poster_480`，插入点在 `poster_h` 之后 → 插入的字段落在原文变体行**之前**，跳过逻辑永远走不到。第 77 轮改成**两遍扫描**（第一遍收集块内已有键 + `poster_h` 行号，第二遍只在「本次真生成过 + 块内没有该键 + 数据里有该字段」三条全满足时插入），并加了重复键守卫（发现即 `exit 1`）。**JSON 重复键不会报错（解析取最后一个值），站点看起来完全正常**，只能靠文本级扫描发现 —— 改回写逻辑后务必跑一次「删掉一个变体文件再重跑」验证幂等。
