# 回归测试套件（tests/）

本目录把两个页面的**回归测试**与**上线复验**脚本随代码一起版本化，不再散落在临时目录里。
两个页面各走各的轮号：观影页脚本带 `_watch` 后缀，游戏时长页（`index.html`）带 `_index` 或无后缀。

## 目录

```
tests/
├── index/           # 【index 站】本地回归套件（对 127.0.0.1:8895 跑）—— 新对话只关心这个目录
├── watch/           # 【watch 站】本地回归套件（同上）
├── retired/         # 已停用的历史套件（断言的功能已被删除，留档不跑、不改判据）
├── unit/            # 采集/差分算法的单元测试（npm test）
├── online/          # 上线后对 https://hyouka-721.github.io/Steam-playtime/ 复验
└── tools/
    ├── perf-audit.mjs / perf-lazy.mjs / ab-css.mjs   # 常驻性能工具（见 tools/README.md）
    ├── pages-poll.mjs                                # 推送后轮询 Pages 是否生效
    └── probes/      # 可复用的取证探针（行高适配 / 多尺寸矩阵 / 像素扫描 / 滚动跳动）
```

**新增脚本放哪里**：能对着任意版本反复跑的 → `tools/`（探针放 `tools/probes/`）；只用一次的（版本号 bump / 取证截图 / 补丁脚本）**随做随删**——git 历史就是归档，不再维护 `archive/` 目录。

## 踩过的坑（脚本层面）

- ⚠️ **两条线并发时，图标文件名会被对方的批量改名顺手清掉**（第 87 轮实测）：index 侧第 92 轮把图标改成 `<名>-<源图哈希>.png` 并清掉旧名 → 我这边刚生成的 `favicon-watch-16/32/48.png`（不带哈希）被同一个 `favicon-*.png` 的清理一并删掉，套件从 21/21 变成「三个文件 MISSING」并且 `sharp` 直接抛 `Input file is missing`。**规矩**：图标一律叫 `<用途>-<源图哈希>.png`，套件里的期望文件名**从源素材文件名推导**（不要手抄字面量），生成完立刻跑一次套件。
- ⚠️ **「行数相同」是代理判据，对方一改文案就失效**（第 87 轮发现 `verify56` B[700] 红，**第 88 轮已改判**）：它拿 watch 页标题行数去比 index 页标题行数（原话「≤首页」），index 侧第 92 轮把站名从 `My Game Time` 改短成 `Game Time` 后，700px 下 index 只剩 1 行、watch 的 `My Watch List` 仍是 2 行 → 判据红了但页面没有任何问题。**改法不是调阈值**，而是换成观影页自己容器的真实约束：整页不横向溢出 + 标题自身 `scrollWidth ≤ clientWidth` + 标题矩形不压头像矩形（「字号与首页同值」已有 `verify58 A3` 直接守着）。这类「两页文案相同」的代理判据，换代时一律换成各自容器的真实约束，别顺手把阈值调松。
- ⚠️ **调色板 PNG 满幅不透明时 sharp 解出的是 3 通道**（第 88 轮踩到）：`fullBleed()` 用 `.png({ palette: true, colours: 32 })` 压体积后，`raw().toBuffer({ resolveWithObject: true })` 回来的 `info.channels === 3`，照旧读 `data[i + 3]` 会把**隔壁像素的蓝值**当成 alpha → 掩码乱掉、bbox 缩水（实测主体占比从 0.78 掉到 0.64）。**规矩**：`const a = ch === 4 ? data[i + 3] : 255;`。
- ⚠️ **数「主体像素」的判据不能绑素材配色**（第 88 轮）：原先写「亮度 < 120 才算主体」，字面上的原因是前两版素材主体是深色；换成亮蓝 `#2F88FF`（亮度正好 125）就被整片漏掉，只剩黑环 → 占比量出 1.000。改成「非透明**且非近白**」（`rgb` 三通道都 > 243 的算背景，涵盖白底与白色圆孔），阈值按新素材重定 0.938 / 0.779。

- ⚠️ **`scripts/media/watch-variants.mjs` 的回写曾经会给同一张海报插两遍变体字段**（远端出现过 198 个重复键）。根因：写回用「遇到 `poster` 行后往下跳过变体行」这种**位置式**判断，而 `watch.json` 里字段顺序是 `poster` → `poster_w` → `poster_h` → `poster_320` → `poster_480`，插入点在 `poster_h` 之后 → 插入的字段落在原文变体行**之前**，跳过逻辑永远走不到。第 77 轮改成**两遍扫描**（第一遍收集块内已有键 + `poster_h` 行号，第二遍只在「本次真生成过 + 块内没有该键 + 数据里有该字段」三条全满足时插入），并加了重复键守卫（发现即 `exit 1`）。**JSON 重复键不会报错（解析取最后一个值），站点看起来完全正常**，只能靠文本级扫描发现 —— 改回写逻辑后务必跑一次「删掉一个变体文件再重跑」验证幂等。

- ⚠️ **10%~90% 渐变带的起止条件极易写反**（第 89 轮 B9 假红，`ramp` 恒 0）：降序剖面下「刚开始过渡」= 首次跌破 `hi − 10%·span`、「过渡结束」= 首次跌破 `hi − 90%·span`；两个条件都写成「暗侧阈值」会让 `s1/s2` 挤在相邻像素上。打印 `t90/t10` 与 `s1/s2` 一眼就能看出反了。
- ⚠️ **CSS px 与设备像素混用**（第 89 轮 B10 假红，对比度 0.96）：`boundingBox()` / `clip` 都是 CSS px，`screenshot()` 出的是 dpr=2 的位图。取样窗按 `pad*2 + 8` 算会越过 pad-left（8 CSS px = 16 设备像素）直接吃进字形，取到金色像素。坐标一律先乘 DPR 再取整，并且用 `Math.round((bb.x - clip.x) * DPR)` 反推元素在**位图**里的左边界（clip 会被 Playwright 取整，别自己算）。
- ⚠️ **「对比度」要分两个口径量，别混**（第 89 轮）：① **局部对比** = 字形核心 vs 紧邻暗晕（`text-shadow` 打出来的那圈），这是眼睛实际判断可读性的量，实测 **5.77:1**；② **字 vs 底盘** = 字形核心 vs 盘面满强度，反映"淡化"的代价，实测 **2.17:1**。底盘淡下去以后只量 ② 会得出「不合格」的结论，但页面看着是清楚的——因为可读性是被 `text-shadow` 撑住的。两个数都要记录，别只留一个。
- ⚠️ **`before` 对照图必须自己注入旧规则**（第 89 轮）：`docs/*.css` 已经是新版时，直接截图得到的 before 和 after 逐像素相同。从 `git show HEAD:docs/watch.css` 里逐字取回旧块，用 `addStyleTag` 注入，还得补 `::before { display:none }` 和 `text-shadow:none`（旧版没有暗晕；`text-shadow` 是**可继承属性**，别漏）。
- ⚠️ **跨线过期的字面量快照，改判而不是调阈值**（第 89 轮一次遇到三条）：`verify66` F4 硬编码 `app.js?v=115`（index 线已 bump 到 v=119）、`verify58` D 的两张标题截图被 index 页的流星画布（`position:fixed` + `z-index:20`，**盖在标题上方**）随机盖住 → md5 永不稳定、`verify56` B11 的「两页页眉同高」差了 1px（`style.css` 的 `.site-header` 在 **index 线第 97 轮** `8c162ed` 加了 `border-bottom: 0`，而 `.w-header` 从建站起就有 `1px solid`）。前两条改判成实质约束（三件资产仍带 `?v=NN` 且不串 `watch.*`；截图前 `window.__fx.toggle()` 关特效）；B11 是**真的几何契约差 1px**，不属本条，留着红并上报，**不许用「减去边框再比」把它抹平**。

- ⚠️ **「取区内最亮像素 = 字芯」只在有底盘时成立**（第 89 轮迭代踩坑）：有 `rgba(8,8,11,.55)` 底盘时背景被压到 L≈0.17，金字 L=0.513 自然是最亮；**底盘删掉后亮海报 L=0.872 比金字还亮**，`Math.max` 取到的是背景，算出来的「字芯 vs 暗晕 5.14:1」其实是「亮底 vs 暗晕」。零填充下正确的三个量：亮底/暗晕（轮廓对比）、金字**理论亮度**（由 computed color 算）/暗晕、以及「未改动亮底像素占比」。别把设计值当测量值，也别把测量值当设计值。
- ⚠️ **证明「零填充」别只 grep CSS，要逐像素**（第 89 轮迭代）：把海报换成纯色合成底后，角标盒**外沿**与**内边距**逐像素都应等于该纯色（实测 `max|ΔL| = 0`）；文字区内还得有 ≥15% 像素完全未被改动（实测 33.7%）—— 若有人偷偷加回半透明块或大范围投影，这两条立刻红。CSS 静态守卫（无 `::before` / 无 `background`）+ 运行时守卫（`getComputedStyle(s,'::before').content === 'none'`）+ 像素守卫，三层都要有。
- ⚠️ **`watch.json` 顶层是 `{ updated_at, items: [...] }`，不是数组**（第 89 轮上线复验 B1 假红）：写「线上卡片数 = 本地条数」时直接 `JSON.parse(...).length` 会拿到 `undefined`；一律 `.items.length`，也别手抄 121 / 124 这类绝对值（CI 每天加数据）。
- ⚠️ **历史 `online85_watch` B4 仍断言「评分牌 1px 描边 + 13px」**，这是第 85 轮的一次性线上快照，第 89 轮换代后已过期；按惯例旧 online 脚本留档不动，**上线复验用当轮最新的那个**，别拿旧 online 的红灯去改代码。
- ⚠️ **一次改动同时碰 CSS 与 JS 时，bump 要处理四种字面量**（第 90 轮）：`watch.css?v=N` / `watch\.css\?v=N` / `watch.js?v=N` / `watch\.js\?v=N`，任何一组漏掉都会让对应套件集体假红（`bump90_watch.mjs` 一次命中 48/35/41/29 处、38 文件）。同批次**再改一次 CSS 就要再 bump 一次**（`bump90b_css.mjs`：49/36 处、37 文件），哪怕中间版从未上线 —— 按红线走，别凭「反正没发布」跳过。
- ⚠️ **`page.route` 的 glob 前缀会误拦同名前缀文件**（第 90 轮白屏）：想拦 `watch.js` 时写 `**/watch.js*`，`data/watch.json` 的前八个字符正好也是 `watch.js`，于是 JS 文本被当 JSON 返回，控制台报 `Unexpected token '/'`，`#w-grid` 一张卡都没有。改成按 pathname 精确判断（`u.pathname.endsWith('/watch.js')`）。另外**注释里千万别写出这个 glob 本身**：`**/` 里的 `*/` 会提前闭合块注释，直接 `SyntaxError`（本轮踩了两次）。
- ⚠️ **角标搬出海报后，海报的 `box-shadow` 会落到标题行上**（第 89→90 轮测量口径失效）：给 `.poster-head` 填纯色合成底，实测 x=8 处 y=32→64 的亮度是 `0.497→0.777` 的垂直渐变而非恒定 `0.8721`，于是「盒外沿逐像素等于纯底」三条全红。这不是页面坏了，是**多了一个干扰源** —— 测量时把 `.poster-pic` 的 `box-shadow` 一并置 `none`，三条立刻回到偏离 0；**不许靠放宽 ≤0.01 的阈值掩盖**。
- ⚠️ **`flex-wrap: wrap` 下长片名会独占第一行**（第 90 轮真 bug）：`.poster-name` 在窄屏是 `-webkit-box` 两行 clamp，`flex-basis: auto` 取的是 max-content（整句不换行、300px+），换行算法判断它一个人就超过 172px 列宽 → 单独成行，评分被挤到第二行，全库 `score.left − name.right` 掉到 **−213**。前 3 张都是短片名，截图完全看不出来，只有**全库逐张量**才暴露。修法是给窄屏片名 `max-width: calc(100% - 64px)`（评分最宽 35 + gap 16 + margin 4 + 余量 9），让「片名 + 评分」必然同排；短片名仍按内容宽，间距照样 12px。
- ⚠️ **「窄屏标题行全库等高」是错判据**（第 90 轮）：第 85 轮起窄屏本来就有 16 张片名折两行（两行 clamp），headH 自然是 `37.1 / 54.7` 两档、差正好一个行高 17.6px。把桌面的「全库单行等高」契约套到窄屏会得到 17.55px 的假极差。换成页面自身的真实约束：**评分与片名严格同排**（顶边差 ≤2px）+ **高度只按片名行数分两档**。
- ⚠️ **before/after 对照图不用改文件**（第 90 轮）：`page.route` 把 `watch.css` / `watch.js` 的响应换成 `git show HEAD:docs/watch.*`，同一份数据、同一浏览器、同一视口，只有这两份资源不同，before 图就是真实的上一版。截**首屏之外的卡片**时先 `scrollIntoView` 并 `waitForFunction(img.complete && naturalWidth>0)`，否则 `elementHandle.screenshot()` 会截出一块空灰底（lazy 图没加载）。
