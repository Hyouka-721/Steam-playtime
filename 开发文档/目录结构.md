## 二、哪些能动、哪些不能动

| 目录 | 能重组吗 | 说明 |
|---|---|---|
| `docs/` | ❌ **绝对不行** | 发布根。移动 = 线上 404，`watch.html` / `index.html` 的相对路径、`sw.js` 预缓存、`manifest` 全部会断 |
| `assets/` | ✅ | 不发布，随便分层；但脚本里的路径常量要同步 |
| `scripts/` | ⚠️ 谨慎 | 已按 pipeline / build / lib / media / watch 分好。脚本靠 `path.resolve(__dirname,'..','..')` 找仓库根，**再挪层级必须同步改 `package.json` 的 6 条 + `.github/workflows/daily.yml` 的 4 条**，否则夜间 CI 静默失败。验证 = 实跑 `node scripts/pipeline/build.mjs`，产物只应差 `generated_at` |
| `tests/` | ⚠️ 谨慎 | 已按 watch / index / online / retired / unit / tools 分好；套件之间靠相对路径互相引（`../tools/expect-stats.mjs`），挪动要一起改 |
| `data/` | ✅ | 按数据种类分目录，纯数据 |
| `开发文档/` | ✅ | 纯文档，随便整理 |

## 三、第 108 轮清理记录（做了什么、为什么）

**1. 删死码：`docs/watch.css` 的 `.st-row-track` 家族（12 行）**

第 101 轮把「类型构成 / 高频标签」两个面板删掉后，`watch.js` 里再也没有任何模板渲染轨道节点（`grep -rn "st-row-track" docs/*.js docs/*.html` = 0），`verify94 B9` 也一直断言运行时轨道数为 0，只剩这段「美观 #6 刻度跑道」样式在空转。

- 清理方式：删 3 条规则（`.st-row-track` / `::after` / `i`），留一行注释说明来历。
- 判据同步：`verify94 A8` 从「守刻度规则**存在**」反转为「守它**已删净**」，理由写进 `ok` 文案。**不是为跑绿调阈值** —— 断言强度没降，方向跟着代码走。
- 顺带全量扫描：`watch.css` 129 个类只剩这 1 个未引用；`@keyframes` 0 个孤儿。

**2. 源素材与发布产物分离：72 张封面原图 37 MB 移出 `docs/`**

`docs/img/songs/` 根层的 72 张原图页面从来不被引用（页面只读 `t/` 里的 480 px 缩略图），但它们跟着 `docs/` 一起部署到了 Pages。搬到仓库根 `assets/songs/` 后：

- 发布体积 **-37 MB**（`docs/img/songs/` 只剩 66 张缩略图 1.9 MB）；
- 回滚能力不变：`verify105 A6` 的判据仍是「每张缩略图都能找到同名原图」，只是原图根从 `docs/img/songs/` 换成 `assets/songs/`，并新增「`docs/img/songs/` 里不许再残留原图文件」；
- 72 个文件全部用 `git mv` 搬走，历史可追。

**3. 文档归类：`CONTINUE-GAMETIME.md` 移入 `开发文档/`，新增本文件与 `CONTINUE-WATCH.md`**

根目录原来堆着 `README.md` + `CONTINUE-GAMETIME.md`，后者只覆盖 index 侧，watch 侧的契约散在各轮 `tests/README.md` 补记里。现在：

- `README.md` 留根（GitHub 惯例），末尾加「开发文档」索引；
- `开发文档/` 放三份不发布的说明：index 侧交接、watch 侧交接、本文件。

**4. 版本 bump：`watch.css?v=43` → `44`（单侧）**

本轮只改了 `watch.css`，`watch.js` 一个字节没动，所以只 bump css 这一条键，`watch.js?v=35` 保持不动 —— 文件没变还 bump 只会让浏览器白丢缓存。

bump 覆盖 **183 处 / 68 个文件**（`docs` + `tests` 全量），两种写法（纯文本与正则转义）一次归零，`songs.json` 里的 90 个 `?v=<8位哈希>` 一个没动。用的规则是 `/v=43(?![0-9a-f])/g` 一条通吃，避免第 107 轮「两种形态漏一半 → 残留守卫假绿」的坑重演。
