## 一、核心目标（产品层）

- **Game Time**：每日 Steam 游戏时长追踪 + 年度/热力图/时间轴/成就可视化；数据由 GitHub Actions 23:30 采集快照，build 生成 `docs/data`，`inline-boot.mjs` 内联进首页。
- **Watch List**：观影记录、年度歌单、年报面板；用户可在页面通过 GitHub Contents API 自行录片（会直接推远端）。
- **氛围**：两页共用的「关 / 流星 / 雨滴」环境层，不抢交互、不遮挡关键数字、切页保持。

## 二、约束条件（工程层）

1. 零构建：`docs/` 既是源码又是发布根，任何相对路径都对应线上 URL。
2. 双页面独立但不重复实现：共用资源只有 `rain.js/css`、`ambience.js`、`fx.js`（watch 侧只加载 fx 画布，不加载 index 样式/脚本）。
3. 历史套件是回归资产，不是垃圾：轮次累积、判据随功能改但理由留痕；不为跑绿调阈值。
4. 数据类断言一律现算；远端随时可能领先。
5. 推送必须 fetch + merge（禁 rebase/force），BOOT 行冲突按既定规则处理。
6. 归档位置固定在 `Documents/Misc/对话成果/<日期_主题>/`，索引与 SHA 清单必须同步。
