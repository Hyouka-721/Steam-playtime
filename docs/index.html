关于数据

—

累计游戏时长来自 Steam 服务器的终身统计（playtime_forever），截至最新快照日，包含开始追踪之前的全部历史。每日记录由 GitHub Actions 每日 23:30（北京时间）抓取快照并与上一份差分得出。

  • 每日数据自基线日（首个快照日）开始积累，基线当天无法计算差分。
  • span_days > 1：表示当天覆盖了对上一次采集之间的若干天（漏采），数值会偏高。
  • 低置信度：出现负增量、异常跳变、家庭共享游戏回归等情况时会被标记，仅作参考。
  • 时长由 Steam 服务器统计，含离线游玩与挂机时间。
