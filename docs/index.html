关于数据

Steam Web API 只提供「累计时长」，不提供每日明细。本站数据由 GitHub Actions 每日 23:30（北京时间）抓取一次快照，与上一份快照做差分得出当日时长。

  • 历史无法回溯：数据自基线日才开始积累，之前的时间无法补回。
  • span_days > 1：表示当天覆盖了对上一次采集之间的若干天（漏采），数值会偏高。
  • 低置信度：出现负增量、异常跳变、家庭共享游戏回归等情况时会被标记，仅作参考。
  • 时长单位为分钟，由 Steam 服务器统计，含离线游玩与挂机时间。
