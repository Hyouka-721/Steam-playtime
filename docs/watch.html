在电脑上跑一条命令就能加第一条（会自动压图、按内容哈希命名、写进 data/watch.json）：

node scripts/watch-add.mjs --img 海报.jpg \
  --title "片名" --watched 2026-10-24 --note "一两句感想"

也可以直接在 GitHub 网页编辑 docs/data/watch.json、把海报传到 docs/img/watch/。
